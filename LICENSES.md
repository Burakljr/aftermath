## Everything else

All other code and content is original work made for this project: the game logic, the
3D models (built in code from simple shapes), the procedural textures, the inline SVG icons,
the synthesised sounds (Web Audio, no sound files), the texts in both languages, the
styles and the tests. No other third-party assets are used, and nothing is fetched from
the network at run time.
